# Макеты и формат deck.json

Каждый макет — слайд-прототип из мастер-шаблона «мерико × ВТБ Образование» (номер в скобках — слайд исходного шаблона).
Как выглядит каждый макет: `references/layouts-1.jpg` (обложки, списки, карточки, фото) и `layouts-2.jpg`
(хайлайты, таблицы, схемы, диаграммы, таймлайн, контакты). Как меняется вид по направлениям — `directions.jpg`.

## Колода

```json
{
  "file": "temp_profile",
  "direction": "vtb",
  "partner": "logos/vshm.png",
  "slides": [ { "layout": "cover", "title": "…" } ]
}
```

| Ключ | Что это |
|---|---|
| `file` | имя файла без расширения (по умолчанию `deck`) |
| `direction` | мастер направления: `vtb` · `family` · `prof` · `china` · `b2b` · `infra` · `private` · `privilege` (`brand.md`) |
| `partner` | PNG логотипа партнёра для обложек `cover-panel`, `cover-diagonal`, `cover-photo` («ВТБ × партнёр»). Нет ключа — на этих обложках полный логотип «ВТБ Образование» без партнёра |

Общие поля любого слайда: `layout` (обязательно), `title`, `notes` — заметки докладчика.

Правила полей:
- Текст — строка; перенос строки — `\n`; список строк склеивается через перенос.
- `items` — элементы слайда по порядку. Если элементов меньше, чем в макете, лишние карточки, иконки и подписи
  удаляются целиком. Если больше — лишние отбрасываются с предупреждением.
- Элемент `items` можно задать строкой — это его `text`.
- Неуказанное поле удаляется со слайда, чтобы в PowerPoint не осталось «Образец текста».
- `icon` — имя из `references/icons.png` (`bank`, `people`…); вариант «Заливка» — `bank-fill`. Можно поставить
  иллюстрацию: `ill-finance-05` (`illustrations.png`). Без `icon` остаётся иконка прототипа — **всегда задавайте
  иконку по смыслу**. `"icon": false` — убрать.
- `photo` — имя из `assets/photos` (`lecture`, `speaker`…) или путь к своему файлу (от папки deck.json).
  Кадрируется по рамке автоматически.

## Фирменный стиль (по умолчанию)

Вид и правила — `house-style.md`, превью — `house-1.jpg`, `house-2.jpg`, пример — `examples/shoifd.json`.
Общие поля: `title` (вывод, до 4 строк), `subtitle` (серым под заголовком), `title2` (вторая строка, 16 pt),
`footnote` (сноска внизу), `notes`. Текст `**так**` — полужирным.

| layout | Поля | items |
|---|---|---|
| `title` | `title`, `note` (синим), `date`, `portrait` | — |
| `chapter` | `kicker` (серый надзаголовок), `title`, `note`, `date`, `date_muted: true` (дата серым) | — |
| `cards` | `height` (необяз., по умолчанию 164 pt) | 2–4 × `title`, `text`, `icon` (необяз.), `accent: true` |
| `stats` | `columns` (необяз.), `height` | до 9 × `value` («17 стран», «80 из 89»), `text` |
| `speakers` | — | до 9 × `name`, `role`, `photo` (путь к фото) |
| `features` | `card_title`, `card_icon` | 6 × `icon`, `text` |
| `rows` | — | 2–4 × `title`, `icon` (водяной знак), `points` (список), `columns` (1 или 2) |
| `datatable` | `table`: `columns`, `rows`, `highlight` (номера выделенных строк, по умолчанию `[0]`), `widths` (доли); `align: "top"` — таблица сразу под заголовком | — |
| `course` | `title` (название курса), `lead` (описание), `modules` («**Тема.** пояснение»), `modules_title` (необяз.) | — |
| `team` | `title` (по умолчанию «Контакты») | до 3 × `name`, `role`, `email`, `phone`, `photo` |

# Макеты мастер-шаблона

Используются, когда нужного вида нет в фирменном стиле: диаграммы, схемы, таймлайн, фото-слайды, хайлайты с иконками.

## Обложки и разделы

| layout | Поля | Что на слайде |
|---|---|---|
| `cover` (9) | `title`, `subtitle`, `meta` (справа вверху: «Осень, 2026») | фон направления на весь слайд, портрет справа |
| `cover-panel` (10) | `title`, `subtitle`, `date` | белое поле, портрет на панели справа, логотип партнёра |
| `cover-band` (11) | `title`, `meta` | горизонтальная полоса-паттерн, портрет |
| `cover-text` (12) | `title`, `meta` | паттерн на весь слайд, без портрета |
| `cover-diagonal` (13) | `title`, `subtitle`, `date` | диагональная панель с портретом — **обложка по умолчанию** |
| `cover-photo` (14) | `title`, `subtitle`, `date`, `photo` | диагональный срез с фото сцены |
| `section` (52) | `title`, `background` (необяз.: `01_03` и т. п.) | фон-паттерн направления на весь слайд |

`portrait` на обложках: по умолчанию портрет направления колоды. Можно указать человека — ключом или именем
(`"portrait": "artyom"` или `"Артём"`, список — `assets.md`), направление (`"prof"`), путь к своему вырезанному PNG
или `false` — без портрета.

## Списки и карточки

| layout | Поля | items (макс.) |
|---|---|---|
| `contents` (15) | `title` | 9 × `title`, `page` («Стр. 5»); номер `num` ставится сам |
| `bullets` (16) | `title` | 4 × `text`; номер `num` ставится сам (01, 02…) |
| `bullets-icons` (17) | `title` | 4 × `icon`, `text` |
| `bullets-conclusion` (18) | `title`, `conclusion` (плашка-вывод) | 3 × `icon`, `text` |
| `cards2` / `cards3` / `cards4` (19 / 21 / 23) | `title` | 2 / 3 / 4 × `icon`, `title`, `text`. Шапки второй и следующих карточек — на градиенте направления |
| `cards2-photo` / `cards3-photo` / `cards4-photo` (20 / 22 / 24) | `title` | то же + `photo` у каждой карточки |
| `process` (25) | `title` | 4 × `label` («Шаг 1»), `title`, `text`; последний шаг выделен |

Число карточек выбирайте макетом (`cards3` для трёх), а не обрезкой `cards4`: так карточки займут всю ширину.

## Карточка + фото

| layout | Поля | items |
|---|---|---|
| `photo-panel` (26) | `title` (белым на градиенте), `lead`, `photo` | 4 × `icon`, `text` |
| `photo-list` (27) | `title`, `header` (плашка), `photo` | 4 × `icon`, `text` |
| `photo-cards` (28) | `title`, `photo` | 4 × `icon`, `title`, `text`; четвёртая выделена |
| `photo-left` / `photo-right` (34 / 35) | `title`, `header`, `photo` (слева / справа) | 4 × `icon`, `text` |
| `laptop` (32) | `title`, `header`, `text`, `text2` | — (мокап ноутбука с логотипом) |

## Цифры (хайлайты)

| layout | Поля | items |
|---|---|---|
| `highlights6` (29) | `title` | 6 ячеек 3 × 2 |
| `highlights8` (30) | `title` | 8 ячеек 4 × 2 |
| `card-highlights6` (31) | `title`, `card_value`, `card_text` (высокая градиентная карточка слева) | 6 ячеек 3 × 2 |

Ячейка: `value` (крупная цифра, VTB Omega UI 60 pt) + `text` (подпись) **или** `icon` + `text`.
Цифра — до 4–5 знаков («120», «95%», «4,5»); единицу измерения — в подпись.

## Таблицы

| layout | Поля |
|---|---|
| `table` (37) | `title`, `table`, `conclusion_title` + `conclusion` (плашка-вывод под таблицей; без них плашки нет) |
| `table-highlight` (38) | `title`, `table`, `card_value`, `card_text` (вертикальная карточка справа) |

```json
"table": {"columns": ["Формат", "Очно", "Онлайн"],
          "rows": [["Полная программа", "450 000 ₽", "300 000 ₽"], ["Один модуль", "90 000 ₽", "60 000 ₽"]]}
```
Шапка: первая колонка Retail Blue, далее цвета акцентов мастера. Строки чередуются как в шаблоне.
До 12 строк и 6 колонок; больше — разбить на два слайда.

## Схемы и диаграммы

| layout | Поля |
|---|---|
| `scheme` (39) | `top1_title`, `top1_text` (выделенный блок слева вверху), `top2_title`, `top2_text`; `box1_title`, `box1_text`; `box2_num`, `box2_title`, `box2_text`; `box3_num`, `box3_title`, `box3_text` (выделен); `box4_text`; `footer` (плашка внизу) |
| `tree` (40) | `root_title`, `root_text` (корень слева), `branch1_title`, `branch1_text`, `leaf1`, `branch2_title`, `branch2_text`, `leaf2` |
| `venn` (41) | `c1_title`/`c1_text`, `c2_…`, `c3_…` (круги), `left1_…`, `left2_…` (выноски слева), `right_title`, `right_text`, `card_value`, `card_text` |
| `charts2` (43) | `chart1_title`, `chart2_title`, `charts` (2 гистограммы), `card_title`, `card_text` |
| `donut` (44) | `chart_title`, `charts` (1 кольцевая), `caption`; справа `side_title`, `side_subtitle`, `side_value` (короткая цифра), `side_value_text`, `side_text` |
| `matrix` (47) | `x_title` (над матрицей), `y_title` (слева), подписи осей `y_top`, `y_bottom`, `x_right`, `x_title2`; items: 4 квадранта × `icon`, `text` |
| `timeline` (48) | items: до 7 точек × `year`, `title`, `text`; точки чередуются над и под осью |

На схемах `scheme`, `tree`, `venn` линии-связи нарисованы в прототипе: заполняйте все поля, иначе останутся
линии без подписей.

Данные диаграмм:
```json
"charts": [{"categories": ["2024", "2025", "2026"],
            "series": [{"name": "Очно", "values": [100, 140, 180]}, {"name": "Онлайн", "values": [50, 90, 160]}]}]
```
Диаграммы — родные диаграммы PowerPoint, данные правятся в Excel. Без `charts` остаются демонстрационные
данные шаблона — скрипт предупредит.

## Контакты

| layout | items (до 2) |
|---|---|
| `contacts` (49) | `name`, `role`, `phone`, `email`, `qr` (путь к PNG QR-кода), `qr_text` (подпись к QR) |

Первая карточка — на градиенте направления, вторая — серая. Без `qr` QR-блок убирается, карточка растягивается
на всю ширину. Демонстрационный QR шаблона в презентацию не попадает.

## Чего нет в скилле
В шаблоне есть ещё «Пузырьковая диаграмма» (42), «Лепестковая диаграмма» (45), «Диаграмма Ганта» (46),
«Мокап телефона» (33) — они нарисованы вручную фигурами, и надёжно заполнить их данными скрипт не может.
Если они нужны: собрать ближайший макет (`charts2`, `table`, `laptop`) и сказать пользователю, что этот слайд
лучше доделать в PowerPoint по образцу шаблона.
