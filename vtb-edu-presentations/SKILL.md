# Презентации «ВТБ Образование»

Скилл превращает содержание в колоду слайдов в визуальной системе «ВТБ Образование»:
пишешь `deck.json` (содержание + выбор макета на каждый слайд), скрипт собирает HTML и рендерит
PNG, PDF и PPTX, затем проверяет, что текст влез.

Файлы:
- `references/brand.md` — цвета, градиенты, шрифты, логотип, сетка, источники значений. Прочитать, если нужно
  нарисовать что-то вне готовых макетов или ответить на вопрос о бренде.
- `references/layouts.md` — 15 макетов, поля, лимиты текста, как выбрать макет. **Прочитать перед написанием deck.json.**
- `scripts/build_deck.py` — сборка. `scripts/render.cjs` — запасной рендер через Node.
- `examples/temp_course.json` — полный пример на 15 слайдов (все макеты); `examples/preview/` — как он выглядит.

## Порядок работы

### 1. Уточнить вводные
Если в запросе нет — спросить (одним сообщением, 2–4 вопроса):
- аудитория и цель (продажа курса, урок, отчёт, защита проекта);
- длительность выступления или число слайдов (ориентир: 1 слайд ≈ 1–2 минуты);
- источник фактов (документ, таблица, сайт); цифры без источника на слайды не ставятся;
- формат на выходе (по умолчанию PDF + PPTX).

### 2. Собрать структуру
Сначала план — список слайдов «макет: мысль слайда». Показать пользователю, если колода больше 8 слайдов.
Правила:
- одна мысль на слайд; заголовок формулирует вывод, а не тему («Модуль 2 короче остальных», а не «Объём модулей»);
- скелет: `cover` → `agenda` (если > 8 слайдов) → [`section` → 2–5 содержательных] × N → `closing`;
- светлых слайдов ≈ 70–80 %, тёмные (cover/section/quote/closing) задают ритм; два тёмных подряд — только раздел → цитата;
- макеты чередовать: не больше двух `bullets` подряд;
- числа — через `stats`/`chart`/`table` с полем `source`;
- не выдумывать факты, имена, цитаты и цифры. Нет данных — оставить поле пустым или поставить пометку
  `[нужны данные]` и сказать об этом пользователю.

### 3. Написать deck.json
Схема и лимиты — `references/layouts.md`. Текст на русском, кавычки «ёлочки», тире «—».
Неразрывные пробелы после коротких слов скрипт ставит сам. Картинки класть рядом с deck.json.

### 4. Собрать
```bash
python3 <путь-к-скиллу>/scripts/build_deck.py deck.json -o out/
```
Нужны: Python 3.9+, Playwright с Chromium (Python-модуль или Node `playwright`), для PPTX — `python-pptx`.
Флаг `--html-only` — только HTML без рендера.

### 5. Проверить
1. Вывод скрипта: все строки `ok`. `ПЕРЕПОЛНЕНИЕ` (код выхода 2) — сократить текст или разбить слайд и пересобрать.
   Уменьшать кегли в CSS нельзя.
2. Посмотреть PNG (минимум обложку и 2–3 самых плотных слайда): нет висячих одиночных слов в заголовках,
   карточки одной высоты, картинки не пикселят.
3. Сверить каждую цифру со источником.

### 6. Отдать
- `deck.pdf` — основной формат для показа и отправки;
- `deck.pptx` — слайды-картинки + заметки докладчика (текст в PPTX **не редактируется**; для правок —
  менять deck.json и пересобирать);
- `slide_XX.png` — для мессенджеров и соцсетей;
- `deck.html` — просмотр в браузере.

## Если нужного макета нет
Добавить функцию `L_<имя>(s, ctx)` в `build_deck.py` по образцу соседних: она возвращает
`(тема, html)`, где тема — `"light"` или `"dark …"`. Использовать только токены и классы из `brand.md`,
новые цвета не вводить. Описать макет в `layouts.md`.

## Ограничения
- Значения бренда взяты из уже свёрстанных материалов «ВТБ Образование» (лонгриды, карусель «Темп», рассылки).
  Figma-файл «мерико × ВТБ Образование» при создании скилла недоступен (коннектор не авторизован),
  поэтому сверка с ним — открытый вопрос (`brand.md` → «Открытые вопросы»).
- Шрифт — Inter как замена корпоративного VTB Group UI.
- Логотип растровый (356×62 px): чёткий при высоте до ~60 px.
